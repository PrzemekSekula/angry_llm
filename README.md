# Angry LLM Negotiation Experiment

This project implements an experimental negotiation pipeline between two LLMs (`LLM_A` and `LLM_B`) using **LangGraph**. The goal is to simulate a negotiation where "Twister" LLMs modify messages based on an emotional "anger" score generated by an observer LLM (`emo_LLM`).

## Project Overview

The pipeline consists of a cyclical graph where:
1.  **LLM_A** proposes a split of credits.
2.  **twist_LLM_A** modifies the message based on the current anger state.
3.  **LLM_B** responds (counter-offer, accept, or reject).
4.  **emo_LLM** observes the interaction and updates an "anger score" (0.0 - 1.0).
5.  **twist_LLM_B** modifies LLM_B's response based on the new anger score.
6.  The modified response is sent back to **LLM_A**, and the loop repeats.

## Installation & Setup

### 1. Prerequisites
-   Miniconda or Anaconda installed.
-   An OpenAI API Key.

### 2. Create Conda Environment
Create and activate a new environment (e.g., `AngryLLM`):
```bash
conda create -n AngryLLM python=3.10
conda activate AngryLLM
```

### 3. Install Dependencies
Install the required Python packages:
```bash
pip install -r requirements.txt
```

### 4. Configure API Key
Create a file named `openai_key.txt` in the `configs/` folder and paste your OpenAI API key into it:
```bash
# configs/openai_key.txt
sk-proj-... (your key here)
```

## Running the Experiment

To run the negotiation simulation:

```bash
python main.py
```

Arguments:
-   `--iterations`: Number of negotiation rounds (default: 5).
    ```bash
    python main.py --iterations 10
    ```

Logs are saved to the `log/` directory.

## Key Files
-   **`main.py`**: The entry point. Parses command-line arguments and initiates the pipeline.
-   **`src/pipeline.py`**: Contains the `StateGraph` definition, node functions (`node_llm_a`, `node_twist_a`, etc.), and the main execution loop.
-   **`src/utils.py`**: Handles logging setup and reading configuration files.
